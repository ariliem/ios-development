# BTS Favorites List — UITableView & Custom Cells 💜

**Student:** Arailym Rakhman  
**Theme:** BTS Favorite Tracks (20 Songs)

## Description
An iOS UIKit application displaying a scrollable `UITableView` of 20 favorite BTS tracks. Each row uses a custom `FavoriteCell` subclass designed in `Main.storyboard` with Auto Layout stack views, featuring album artwork, track title, album/year subtitle, and a 5-star SF Symbols rating (`star.fill` / `star`).
