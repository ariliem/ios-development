# BTS Playlist Roulette 💜

**Student:** Arailym Rakhman  
**Category:** BTS Favorite Tracks (10 Songs)

## Description
A single-screen iOS UIKit application built with Storyboard (no Auto Layout constraints) that displays a random favorite BTS song card on each button tap. Each card features custom album artwork, the track title, and a short description, ensuring the same track never appears twice in a row.
