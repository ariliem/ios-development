# BTS Favorites Navigator 💜

**Student:** Arailym Rakhman  
**Theme:** BTS Discography (20 Favorite Tracks)

## Description
An iOS UIKit application built in `Main.storyboard` using `UINavigationController` and Auto Layout. The main screen displays a scrollable list of 20 favorite BTS tracks with custom album art and song titles. Tapping any row triggers a `Show` segue (`showDetail`) using `prepare(for:sender:)` to open the Detail screen displaying the full cover art, album & release year subtitle, a 5-star SF Symbols rating, and a 3-sentence description.
